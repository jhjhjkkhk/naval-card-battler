海军卡牌战斗游戏（WIP）
二战题材 · 上帝视角 · 回合制卡牌 + 实时演算

60 秒规划期内同时下达指令，回合结束后引擎按操作时间戳 1:1 复刻整场战斗。

本仓库收录核心 C# 脚本（约 2,300 行，部分脚本陆续补充中）。完整 Unity 工程还包含场景、预制体与美术资源，如需可运行版本可联系我提供。

玩法设计
阶段	内容
规划期（60 秒）	出卡牌（立即生效）；移动、攻击消耗决策值并记录时间戳
演算期	按时间轴回放移动与攻击；可暂停、可 2× 快进
卡牌：6 类效果（攻击/防御增减、回血、抽牌）、4 档稀有度、可配置持续回合
决策值：每回合 +5，上限 10；单次移动消耗 1 点且每回合限一次，攻击消耗 1 点
船只：只能前进、不能原地掉头；最小转弯半径决定笨重感（航母迟钝、驱逐舰灵活）
地图：平顶六边形网格，六边形中心为落点；可达格与攻击格高亮提示

技术亮点
WEGO 回合模型：规划期收集带时间戳的有效操作（移动/攻击），演算期按同一时间轴回放；卡牌走「即时生效」通道，不参与回放。
决策值驱动的行动经济：卡牌消耗行动力，移动/攻击消耗决策值，两套资源分离，避免「无脑出牌」。
舰船惯性表现：加减速曲线 + 转向限速（角速度 ≤ 速度 / 最小转弯半径），制造二战舰船的笨重感。
